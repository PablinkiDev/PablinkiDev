### 🍜 Kuaizi — Sistema de Gestión Gastronómica

**Proyecto final universitario | UTN FRA**

Aplicación multiplataforma desarrollada para digitalizar
y optimizar la operación de un restaurante, integrando
los diferentes procesos de gestión y atención al cliente.

**Funcionalidades principales:**
- Autenticación y gestión de usuarios con roles y permisos.
- Administración de mesas y listas de espera.
- Gestión de pedidos para cocina y barra.
- Notificaciones y actualizaciones en tiempo real.
- Encuestas, juegos y comunicación con los clientes.
- Gestión de pagos, facturación y propinas.
- Integración de códigos QR para la interacción de los clientes.

**Tecnologías:**
